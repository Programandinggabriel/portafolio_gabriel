Proyectos

1. Product Tracker

Aplicación web para seguimiento de productos y cambios de precio.

Visitar proyecto

Permite consultar productos, agregarlos a favoritos y configurar alertas para realizar seguimiento de precios.

Proyecto full stack actualmente en desarrollo, orientado a permitir que los usuarios consulten productos, los guarden como favoritos y configuren alertas para realizar seguimiento de sus precios. La aplicación integra una API externa de productos y utiliza una base de datos para almacenar la información asociada a las interacciones de los usuarios.

Personalmente quiero que este proyecto tenga mas funcionabilidades y pueda crecer con el paso del tiempo.

¿Qué problema resuelve?

Evita que el usuario tenga que revisar constantemente una tienda virtual para saber si sus artículos favoritos bajaron de precio. La aplicación monitorea los precios y envía alertas por correo cuando detecta una disminución.

Desiciones tecnicas

  1. Integración con API eBay
  2. Redis para reducir solicitudes repetitivas
  3. Tareas programadas para detectar cambios de precio

Tecnologías:

Node.js · Next.js · SQL · Redis · Tailwind CSS · API externa
